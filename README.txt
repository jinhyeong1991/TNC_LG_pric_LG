TNC LG전자 렌탈료 검수 (개발서버 전용, v0.1.0)

[무엇을 하나]
LG전자 검수 엑셀(카테고리별 시트)의 구독료·서비스타입·방문주기를 사이트의 "렌탈사명 LG전자" 상품과 비교하고,
다른 값은 수정해서 사이트에 반영합니다. (분석 → 확인 → 실행) 분석 단계에서는 사이트를 수정하지 않습니다.

[설치]
1. chrome://extensions → 개발자 모드 ON
2. "압축해제된 확장 프로그램을 로드합니다" → 이 폴더(TNC_LG전자_검수) 선택
3. 상품 목록 페이지(admin/goods.php)를 F5로 새로고침 → 왼쪽 아래 노란 사자 아이콘 → 클릭하면 패널이 열림
   (기존 "TNC 렌탈료 엑셀 일괄수정" 확장과 같이 설치해도 됩니다. 저장소 이름이 달라 서로 영향 없음)

[사용 순서]
① 엑셀 불러오기: "lg전자 사이트 검수 파일.xlsx" 선택 (6개 카테고리 시트를 자동 인식: 냉장고·쿠킹·TV·공청기·에어컨·리빙)
② LG전자 렌탈료 검수: 총괄 또는 카테고리를 고르고 [분석 시작]
   - 사이트에서 렌탈사명 LG전자 상품을 모두 읽고, 엑셀 줄과 짝지어 상품 상세를 확인합니다
③ 결과 표에서 상태 칩으로 걸러 보고, 변경할 건을 체크 → [선택한 건 사이트에 반영] (처음에는 [연습]으로 1건 확인)
   - 반영된 건은 '변경완료', 실패한 건은 '변경 실패'로 바뀝니다
④ 사이트 단종 정리: 엑셀에 없는 LG전자 상품을 찾아 단종(숨김 → 삭제) 처리 (기존 확장과 같은 기능)

[비교 기준]
- 구독료: 엑셀 36/48/60/72개월 ↔ 사이트 렌탈사 폼 계약36/48/60/72개월
- 서비스타입: 라이트 = 라이트플러스(같은 서비스). 프리미엄·베이직(자가) 등은 서로 다름
- 방문주기: 상품명 끝 (서비스/N개월방문관리) 과 엑셀 방문주기
- 추가안내정보: "케어솔루션 총요금 N원" = 72개월 구독료 × 72, "(…N개월 방문 기준)"의 방문주기도 엑셀에 맞춤
- 모델명: 엑셀의 .AKOR/.CKOR/.AKRG 같은 구분 코드는 떼고 비교. 사이트 검색문구에 적힌 모델코드도 함께 봄
- 에어컨: 모델명 끝에 M이 붙은 것(매립형)과 안 붙은 것(일반형)은 같은 모델
- TV: 스탠드/벽걸이/밀착벽걸이는 한 상품. 가격이 같으면 36·48·60·72개월 한 세트,
      가격이 다르면 계약36개월_벽걸이 / _스탠드 / _밀착형벽걸이 칸으로 나눠 36·48·60개월 입력
      (제품모델명에서 끝의 S/W/L(스탠드/벽걸이/밀착)을 뗀 것이 사이트 모델명. 예: OLED83G6KS → OLED83G6K)

[상태]
- 변경 있음 / 변경 없음(일치) / 사이트에 없음(신규 등록: 노란색 대상) / 엑셀 값 충돌 / 확인 필요 / 변경완료 / 변경 실패
